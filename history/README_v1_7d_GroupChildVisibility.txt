UBE v1.7d - Group Child Visibility Debug
=======================================

Adds a preview-only child visibility tool for transform/group assembly previews.

Hotkeys:
  V        Cycle hidden child: hide child 1, then child 2, ... then show all
  Shift+V  Show all group children again

This is useful when a parent/group preview looks like one child is offset or
rotated incorrectly.  The status bar reports the one-based child number and
child object name, for example:

  Group child hidden: 2/4  CrystalFormingMachine_metalPS

No export behaviour is changed.
