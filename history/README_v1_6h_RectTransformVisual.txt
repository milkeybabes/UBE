UBE v1.6h - RectTransform Visual Preview
=======================================

Adds an educational preview-panel visual for RectTransform records.

The preview draws:
- parent Canvas/panel frame
- anchor pin or stretch anchor rectangle
- approximate UI element rectangle
- pivot dot
- anchored-position offset line
- simple +X/+Y UI axis guide

This is intentionally an approximate visual aid, not a full Unity layout engine.
It helps explain how RectTransform anchors, pivot, sizeDelta and anchoredPosition
place flat UI panels/buttons/pop-up elements inside a Canvas or parent UI object.
