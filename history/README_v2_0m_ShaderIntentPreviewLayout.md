# UBE v2.0m Build 275 — Shader Intent Preview Layout

## Tidier right-hand information card

The symbolic Shader/Material intent preview now:

- moves the right-hand card upward;
- makes the card slightly wider and substantially taller;
- reduces excess vertical spacing between the four response bars;
- places detected-ingredient chips left-to-right;
- wraps chips onto another row only when required by the available width;
- keeps all labels and chips inside the rounded card.

The shader analysis and displayed values are unchanged; this update only improves the preview layout.
