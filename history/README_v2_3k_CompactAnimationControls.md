# UBE v2.3k Build 324 — Compact Animation Controls

The animation transport now uses the shorter **Export GLB** button label. The
function is unchanged: it still exports the currently resolved animated GLB.

The Speed selector is also constrained to a compact width sized for entries
such as `0.25×`, removing unused space before the drop-down arrow. Together
these changes free horizontal room for the duration limit and growing
frame/time counter, reducing unnecessary window-width changes during preview.
