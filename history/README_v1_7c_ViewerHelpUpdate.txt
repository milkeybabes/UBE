UBE v1.7c Viewer Help Update
================================

Updated the 3D Preview Help popup so it documents the newer keys added through the v1.5/v1.6/v1.7 work:

- B: cycle displayed texture source
- N: normal/bump texture debug view
- L: lit + normal/bump preview
- [ / ]: bump strength
- G: flip normal-map green/Y channel
- F: flat/helper preview
- M: UV domain/remap mode
- T: texture tint / neutral material toggle

Also added a short reminder in the help for special preview types: Camera frustum, BoxCollider, RectTransform, Shader/Material intent cards, and transform-group assembly preview.
