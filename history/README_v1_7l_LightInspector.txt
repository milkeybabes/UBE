UBE v1.7l - Light Inspector / Light Preview

Adds a specialised Unity Light inspector and symbolic preview.

Inspector shows:
- Light type: Spot / Directional / Point / Area / Rectangle / Disc
- Colour, intensity, range, spot angle and inner spot angle
- Shadow mode, shadow strength, bias and resolution where exposed
- Bake/mode field, bounce/indirect multiplier, render mode and culling mask
- Cookie texture / flare / colour temperature where exposed

Preview shows:
- Directional light as sun-style rays
- Point light as a range sphere/bulb
- Spot light as a cone with angle/range labels
- Area/rectangle/disc light as a panel source

This is an educational/influence-shape preview, not a Unity renderer.
