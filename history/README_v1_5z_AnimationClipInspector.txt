UBE v1.5z AnimationClip Inspector
=================================

Adds a specialised AnimationClip inspector.

Shows:
- estimated duration from keyframes/events
- sample rate, wrap mode, legacy/compressed flags
- position / rotation / euler / scale / float / PPtr curve groups
- target paths and animated property names where exposed
- keyframe counts, time ranges and value ranges
- binding constant summaries
- muscle/dense/streamed clip data summaries
- animation events

This is inspection only: no playback/preview/export yet.
