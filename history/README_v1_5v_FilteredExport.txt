UBE v1.5v - Filtered Export
==========================

Adds right-click export actions that follow the current quick filter/search box.

New context-menu actions when the search box is not empty:

- Export filtered results in this branch... (N)
  Exports only visible/search-matching exportable assets under the branch you right-clicked.

- Export all filtered results... (N)
  Exports all visible/search-matching exportable assets in the current tree.

This is useful for typing `ball`, right-clicking the Objects branch/root, and exporting only the filtered ball objects instead of all thousands of objects.

Existing features retained from v1.5u:
- OpenGL lit + normal-map preview hotkeys
- GLB golf-ball texture/normal mapping fixes
- GLB export with base + normal textures
