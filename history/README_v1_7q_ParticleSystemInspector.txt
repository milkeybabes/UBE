UBE v1.7q - ParticleSystem Inspector / Preview
================================================

Added lightweight inspectors for Unity ParticleSystem and ParticleSystemRenderer.

What it shows:
- ParticleSystem playback/lifetime fields where exposed
- start lifetime, start speed, start size, start colour
- emission rate / bursts where exposed
- shape/emitter type, radius, angle, mesh/sprite references where exposed
- velocity/colour/size/trail module summaries when UnityPy exposes them
- sibling ParticleSystemRenderer link
- renderer mode, sort mode, material slots, mesh/trail material references
- billboard/streak controls such as velocity scale, length scale, min/max particle size

Preview:
- symbolic emitter/particle-cloud view in the top preview panel
- shape-aware visual for cone/box/sphere/mesh-style emitters
- settings card for duration, looping, max particles, rate, lifetime, speed, size, colour and materials

This is not a runtime particle simulator. It is an educational/diagnostic view to explain the effect setup.
