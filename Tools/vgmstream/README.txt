OPTIONAL FSB5 AUDIO DECODER
===========================

Place the complete Windows vgmstream command-line bundle in this folder:

    vgmstream-cli.exe
    [all DLL files supplied with the same download]

UBE will detect it automatically the next time an FSB5 AudioClip is selected.
You can also choose the executable from the AudioClip panel with
"Locate vgmstream...".

The decoder is not included in UBE.  UBE keeps the original FSB5 data and uses
vgmstream only to make a temporary WAV for playback.

For Windows and macOS installation instructions, see AUDIO_HELP.txt in the UBE folder.
